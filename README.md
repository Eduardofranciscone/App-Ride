🚗 App-Ride

O App-Ride é uma aplicação web que simula um sistema de corridas, permitindo acompanhar a velocidade em tempo real, registrar viagens, visualizar trajetos em um mapa e salvar o histórico de corridas diretamente no navegador.
O foco do projeto é praticar conceitos de JavaScript, manipulação do DOM, uso de APIs de geolocalização, armazenamento local e organização de interfaces com Bootstrap.

✨ Funcionalidades

  📏 Cálculo da velocidade atual durante a corrida
  🗺️ Visualização do trajeto da viagem em um mapa
  ➕ Criação de novas corridas
  🕒 Histórico de viagens já realizadas
  💾 Salvamento automático das viagens usando LocalStorage
    Mesmo ao fechar o navegador, os dados não são perdidos
  📱 Interface responsiva com Bootstrap

🛠️ Tecnologias Utilizadas

  HTML5 – estrutura da aplicação
  CSS3 – estilização e layout
  JavaScript – lógica da aplicação
  Bootstrap – responsividade e componentes visuais
